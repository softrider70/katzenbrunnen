# Memory Refresh Trigger

Kurzer Befehl um Cascade anzuweisen, alle Memories und die readme.md frisch einzulesen und zu beachten.

## Befehl

```
/refresh
```

**Aktion:** Cascade liest frisch ein:
- Alle globalen Regeln (global_rules.md)
- Alle projektbezogenen Memories
- Die readme.md

Diese Informationen werden für alle weiteren Aktionen beachtet.
